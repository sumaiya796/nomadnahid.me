Blog · E-commerce tracking guide

How I set up e-commerce tracking: GTM, GA4 events, Google Ads purchase conversions and Enhanced Conversions

A store needs sales data it can trust before it makes ad decisions. If purchases aren't tracked properly, ROAS is a guess and Smart Bidding learns from the wrong signals. This is the setup I use.

01Make GTM the single home for every tag

Put every tag in Google Tag Manager rather than spreading them across theme code and plugins. One place to manage tags means fewer duplicates, fewer gaps and easier testing.

02Send GA4 e-commerce events

Track the shopping journey as GA4 e-commerce events, ending with the purchase. Pass the order value and currency with each purchase so revenue in GA4 matches the store.

03Add Google Ads purchase conversions

Set up a Google Ads purchase conversion that fires on completed orders, carrying the order value. This is what lets campaigns optimize for sales and report real ROAS.

04Turn on Enhanced Conversions

Enhanced Conversions sends hashed first-party customer data with the conversion, which helps Google Ads match sales it would otherwise miss.

05Link Google Ads with GA4, then test

Link the two accounts so data flows both ways, then test every tag in GTM Preview before publishing.

What you get

  • Real ROAS the store can trust
  • Ad decisions based on actual sales

Blog · Lead-gen tracking guide

Lead-gen tracking across Google, Meta and GA4: forms, Conversions API and Enhanced Conversions

When you advertise on Google and Meta, each lead needs to be counted on every platform, even though browser restrictions cause data loss. This is how I set it up so one lead shows up in Google Ads, Meta and GA4.

01Track forms and key actions in GTM

Set up Google Tag Manager events for form submissions and the other actions that signal a real lead. These events feed every platform that follows.

02Create Google Ads conversions for qualified leads

Count the leads that matter as Google Ads conversions, so bidding optimizes toward qualified leads, not just any click.

03Add Meta Pixel and the Conversions API

The Meta Pixel tracks leads in the browser. The Conversions API sends the same events from the server, so Meta still receives leads that browser restrictions block.

04Turn on Enhanced Conversions

Enhanced Conversions on Google Ads recovers more leads by matching hashed first-party data from the form.

05Check it all in GA4

Send the same lead events to GA4, so you can compare platforms against one neutral view.

What you get

  • Leads tracked across every platform
  • Less data lost to browser restrictions

Tracking guide · GA4 + GTM

How to set up GA4 and Google Ads conversion tracking the right way (with GTM)

By Md Nahid Hossain · 28 November 2026 · 6 min read

If your Google Ads account is making decisions from bad conversion data, every bid, budget and "winning" ad is built on sand. The good news: a clean setup with Google Tag Manager (GTM), Google Analytics 4 (GA4) and Google Ads is not complicated once you follow a clear order. This is the order I use on new accounts.

Why tracking comes before anything else

Smart Bidding strategies such as Maximize Conversions, Target CPA and Target ROAS learn from the conversions you tell Google about. If a form submission is counted twice, if page reloads count as leads, or if newsletter sign-ups are mixed in with real enquiries, the system will happily optimise toward the wrong thing. It is not the algorithm's fault. It is doing exactly what the data says.

So before changing keywords or budgets, I make sure three things are true: every important action is tracked, each action is counted once, and Google Ads knows which actions actually matter to the business.

Step 1: Decide what a conversion really is

Start with a short list, written in plain language, before you open any tool. For most businesses it looks something like this:

  • E-commerce: completed purchase (with order value), and optionally add to cart and begin checkout as supporting signals.
  • Lead generation: submitted enquiry form, phone call from the ad or website, booked appointment, and sometimes WhatsApp or chat clicks.

Then split the list into two groups. Primary actions are the ones you would happily pay for: a sale, a qualified lead, a booking. Secondary actions are useful to watch but should not drive bidding, such as a brochure download or a click on an email link. This distinction matters later, inside Google Ads.

Step 2: Put one GTM container on every page

Install the GTM container snippet once, in the site's header and body, on every page. On Shopify, WordPress and most site builders there is a standard place for this. The goal is that GTM becomes the single home for your marketing tags.

A common problem I see is tags living in three places at once: a plugin, the theme code and GTM. That is how duplicate conversions happen. If you move to GTM, remove the old hard-coded tags or plugin settings that send the same events, and keep a short note of what you removed.

Step 3: Add the Google tag and a Conversion Linker

Inside GTM, create a Google tag using your GA4 measurement ID (it starts with "G-") and fire it on all pages. This sends page views and the basic data GA4 needs.

Next, add a Conversion Linker tag that also fires on all pages. It stores the ad click information so that a conversion later in the visit can be matched back to the Google Ads click. It is a small tag, but leaving it out is one of the most common reasons conversions go missing.

Step 4: Build triggers for real actions, not just page views

This is where most setups go wrong. A "thank-you page" trigger works only if that page cannot be reached any other way and is not reloaded or bookmarked. When those conditions are not safe, use a trigger based on the action itself:

  • Forms: a successful form submission event. Many form tools push a message to the data layer when a form is sent; use that rather than a button click, so failed or empty submissions are not counted.
  • Purchases: the purchase event from your store's data layer, which should include the order ID, value and currency.
  • Phone and WhatsApp clicks: a click trigger on links that start with "tel:" or point to WhatsApp.

Name everything clearly, for example "Trigger: Lead form success" or "Event: purchase". The next person who opens the container, possibly you in six months, will thank you.

Step 5: Send GA4 events

For each trigger, create a GA4 event tag. Where possible, use Google's recommended event names, such as generate_lead for leads and purchase for orders, because GA4 reports understand them out of the box. For purchases, pass the transaction_id, value and currency parameters, plus the items if your store provides them.

In GA4, mark the events that matter as key events (this is what GA4 now calls conversions). Keep the list short and meaningful.

Step 6: Create Google Ads conversion actions

You have two ways to get conversions into Google Ads: import key events from GA4, or use the Google Ads conversion tag directly in GTM. Both work. My usual preference for the main purchase or lead action is the native Google Ads conversion tag, because it records conversions in Google Ads directly and pairs well with Enhanced Conversions. GA4 imports are fine for secondary actions or simpler setups.

Whichever you choose, avoid counting the same action twice as primary, for example a native purchase tag and an imported GA4 purchase both set to primary. Pick one as primary and set the other to secondary, or remove it.

For each conversion action, check the settings:

  • Count: "Every" for purchases, "One" for leads, so one person submitting a form twice is one lead.
  • Value: the real order value for sales; for leads, a consistent estimated value if you know roughly what a lead is worth.
  • Primary or secondary: only actions you would pay for should be primary.

Step 7: Turn on Enhanced Conversions

Enhanced Conversions sends hashed first-party data, such as the email address entered in a form or checkout, along with the conversion. Google uses it to match conversions it would otherwise lose, for example when cookies are limited. In GTM, you can supply this through a user-provided data variable on the conversion tag. Make sure your privacy policy covers it.

Step 8: Respect consent, especially for European visitors

If you have visitors from the EU or UK, you need a consent banner and Google Consent Mode configured correctly, so tags behave according to each visitor's choice. Consent Mode is set up in GTM alongside your consent tool. It is worth doing properly: without it, you risk both compliance problems and gaps in the data your campaigns rely on.

Step 9: Test before you publish

Never publish a container without testing. My routine:

  1. Open GTM Preview (Tag Assistant) and complete each action yourself: submit a test form, click to call, place a test order if possible.
  2. Check that each tag fires once, on the right action, and that values and IDs are filled in.
  3. Open GA4 DebugView and confirm the events arrive with the right parameters.
  4. After publishing, watch the conversion action status in Google Ads over the next days, and compare the numbers with your CRM, inbox or store orders.

Small differences between platforms are normal, because each one counts slightly differently. Large gaps usually point to a missing tag, a duplicate, or a trigger that fires on the wrong thing.

Common mistakes to avoid

  • Counting page views of a thank-you page that can be reloaded or reached directly.
  • Having the same purchase tracked by a plugin and by GTM.
  • Setting every action, including micro-actions, as primary.
  • Forgetting the Conversion Linker tag.
  • Publishing changes without testing in Preview mode.

The result you are aiming for

A good setup is boring in the best way. Conversions in Google Ads roughly match what you see in your store or inbox, each lead or sale is counted once, and the bidding system learns from the actions that actually grow your business. That is the point where it makes sense to start scaling budgets.

This is the same order I follow on client accounts: audit what exists, decide what counts, rebuild the tags in GTM, and validate every event before campaigns depend on it.

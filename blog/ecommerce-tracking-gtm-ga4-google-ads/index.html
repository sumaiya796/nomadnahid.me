How I set up e-commerce tracking: GTM, GA4 events, Google Ads purchase conversions and Enhanced Conversions

By Md Nahid Hossain · 26 November 2026 · 1 min read

A store needs sales data it can trust before it makes ad decisions. If purchases aren't tracked properly, ROAS is a guess and Smart Bidding learns from the wrong signals. This is the setup I use.

01. Make GTM the single home for every tag

Put every tag in Google Tag Manager rather than spreading them across theme code and plugins. One place to manage tags means fewer duplicates, fewer gaps and easier testing.

02. Send GA4 e-commerce events

Track the shopping journey as GA4 e-commerce events, ending with the purchase. Pass the order value and currency with each purchase so revenue in GA4 matches the store.

03. Add Google Ads purchase conversions

Set up a Google Ads purchase conversion that fires on completed orders, carrying the order value. This is what lets campaigns optimize for sales and report real ROAS.

04. Turn on Enhanced Conversions

Enhanced Conversions sends hashed first-party customer data with the conversion, which helps Google Ads match sales it would otherwise miss.

05. Link Google Ads with GA4, then test

Link the two accounts so data flows both ways, then test every tag in GTM Preview before publishing.

What you get

  • Real ROAS the store can trust
  • Ad decisions based on actual sales

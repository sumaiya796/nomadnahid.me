FAQ

Common questions.

Do I need server-side tracking?

Not always. For many small accounts, a clean web GTM setup with Enhanced Conversions is enough. I tell you honestly if server-side isn't worth the running cost yet.

Does server-side tracking cost money to run?

Yes. The server container needs hosting, which has a monthly cost that depends on your traffic. I explain the options before we start.

Does it replace consent requirements?

No. Consent still applies. I make sure the server setup respects the consent signals from your site.

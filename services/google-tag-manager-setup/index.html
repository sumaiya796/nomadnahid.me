FAQ

Common questions.

Do I need a developer to install GTM?

Not always. On Shopify, WordPress, Webflow and most site builders I can install it with access. For custom sites I send your developer exact instructions.

Will GTM slow down my site?

A well-built container adds little. Cleaning out old and duplicate tags often helps, and I keep the container lean.

Can you track WhatsApp and chat clicks?

Yes. I track clicks on WhatsApp links, chat widgets and phone numbers as events, and set up the important ones as conversions.
